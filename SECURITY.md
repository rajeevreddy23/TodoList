# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please email us instead of using the issue tracker. Please do not publicly disclose the vulnerability until it has been addressed.

## Supported Versions

We support security updates for the current version. Historic versions may not receive updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Security Best Practices

- Keep your browser updated
- Use HTTPS when accessing web applications
- Do not store sensitive information in localStorage
- Clear your browser data regularly
